# Product

## Register

product

## Users

Developers and technical content managers who keep articles, posts, and custom content in GitHub repositories. They use MDVault to write, organize, preview, and publish Markdown without manually managing files and media.

## Product Purpose

MDVault makes Git-backed content practical to edit while preserving plain Markdown, repository ownership, and full version history. Success means users can complete common publishing workflows quickly without a database, external media host, or proprietary content format.

## Brand Personality

Clean, practical, developer-friendly.

## Anti-references

Heavy traditional CMS interfaces, decorative dashboards, proprietary editing formats, surprising custom controls, and workflows that hide or weaken the Git and Markdown source of truth.

## Design Principles

1. Keep the tool out of the writer's way.
2. Preserve Markdown portability and repository ownership.
3. Prefer familiar, keyboard-accessible editing patterns.
4. Reveal advanced controls only when they are relevant.
5. Keep preview and published rendering consistent with the editor.

## Accessibility & Inclusion

Use semantic controls, visible focus states, keyboard-complete interactions, reduced-motion support, sufficient contrast, and descriptive labels. Target WCAG 2.2 AA for user-facing editor workflows.
